## Зображення

У Figma фото — це вихідні (raw) зображення, які в слотах кадруються (зсув і масштаб у %). Щоб збігалось з макетом, у проєкті
беруться **ті самі raw-файли**, а кадр відтворюється custom properties (`--l-*`, `--t-*`, `--w-*`, `--h-*`, `--pos-*`) у `src/data/catalog.pug`.

| Файл у `images-src/`                                      | Де в макеті                                                      |
| --------------------------------------------------------- | ---------------------------------------------------------------- |
| `hero.png`                                                | hero, усі ширини (джерело 16:9)                                  |
| `banner.png`                                              | нижній банер (квадрат)                                           |
| `logo.png`                                                | логотип (растр, кадрується в `.logo`)                            |
| `product-a5.png`, `product-hx.png`, `product-theatre.png` | картки Recommended                                               |
| `portable-1.png`, `portable-2.png`                        | Portable speakers (744/1260); на 320 перше — `portable-1-sm.png` |
| `earphones-1.png`, `earphones-2.png`                      | Earphones                                                        |
| `smart-home-1.png`, `smart-home-2.png`                    | Smart Home (на 320 друге — `smart-home-2-sm.png`)                |

Завантаження: `npm run figma:assets` (тимчасові посилання, діють 7 днів) або вручну: у Figma виділити шар → Fill → клік на мініатюрі зображення → Download.
Потім `npm run images`.

Іконки (phone, burger, close) вбудовані інлайн у `src/mixins/icon.pug` — SVG з Figma. Hover бургера — стилями, без окремого файлу.
